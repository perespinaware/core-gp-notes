# Core GP Notes

Interactive, narrated revision notes for the MRCGP AKT and SCA, by Peres Pinaware.

Each lesson is a single self-contained HTML page, grouped by category:

- `cardiology/`
- `dermatology/`
- `statistics/`
- `sca/`

The homepage (`index.html`) lists every category and lesson.

For exam revision only, based on NICE and other UK guidance at the time of writing. Not clinical advice.
